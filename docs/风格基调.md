# 风格基调（v2 定稿）

> 一句话：**古籍手记的质感 + 现代移动卡片** —— 低饱和暖纸、墨色文字、克制的类型色。零文字标签：类型只靠序号与色带区分。

## 设计原则

1. **舒服优先**：低饱和色板、暖纸底、充足留白，长时间阅读不刺眼。
2. **零标签**：全程不出现"主线/支线"字样，用**序号/色带/卡片形制**区分类型。
3. **一卡一步**：主流程/大支流每步一张卡，视觉重心在"这一步干什么"。
4. **链接即窗口**：窗口提醒、关联跳转全部用"链接胶囊"表达，点即达某步。
5. **移动优先**：640px 阅读容器、44px 触控目标、拇指可及。

## 字体

- **标题**：衬线（Noto Serif SC / Songti SC），武林秘籍手记感；字号 15–17px。
- **正文**：系统黑体（-apple-system / PingFang SC / Noto Sans SC），14.5px、行高 1.7。
- **数字/编号**：tabular-nums，等宽对位。

## 组件规范

### 主线步骤卡
白卡、圆角 14px、发丝边框；**金色衬线大序号**（01）竖排左侧；标题 16px 半粗；正文 14.5px。
关联折叠条（灰色小字）：`↗ 关联 2 处 · 武家旧事/伤魂鸟`，点开列出链接胶囊。

### 大型支线步骤卡
同白卡 + **4px 朱砂左边条**；任务名即标题（无"支线"字样）；步骤序号小号朱砂。
`window` 元行 → **窗口条**：朱砂淡底、左朱砂边、⚠ 图标、文字含出链（点跳主线步）。

### 小型支线内嵌块
苔绿淡底圆角块、无序号，直接在主线流程中出现处展开完整步骤；标题前小圆点。

### 备注
灰色斜体小字，无卡无边框，紧随所属步骤。

### 徽章（小胶囊）
存档=蓝、必选=赤、掉落=棕；圆点 + 文字，淡底，字号 12px。

### 链接胶囊
灰底圆角 pill：`↗ 碧海仙踪 · 百年传承`；点击跳目标步骤（hash 路由）。
**回链区**（卡片底部）：`← 从这些步骤跳入：…` 灰底小字列表。

### 状态
完成 = 整卡不透明度 0.55 + 金色序号变绿勾；进度存 localStorage。

## 布局

- 阅读容器 max-width 640px 居中；章组标签（入门之前/入门弟子/…）作顶栏切换。
- 卡片间距 12px；步骤正文与编号区垂直居中错落，扫描感强。
- 顶栏：纸色延续、墨字粗体标题 + 金色 logo 点。

## 落地

- `public/style-preview.html` —— 静态预览样板（浏览器直接看，含交互）。
- 前端重构时把 token 写入 `src/styles.css`（CSS 变量），组件按本规范实现。
