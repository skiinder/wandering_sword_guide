# MD 渲染规则（逸剑风云决·攻略）

> 内容唯一规范：**所有攻略内容都是 Markdown 源码**，前端由构建管线统一渲染。
> 编译链路：`content/flows/**/*.md` → `tools/build-content.mjs` → `public/data/flows.json` → 前端（胶囊链接 / 回链 / 窗口条 / 徽章）。

## 1. 文件组织

```
content/flows/
├── main/01-初出茅庐.md        # 主线章（章序起名：01-, 02-, …）
├── quest/碧海仙踪.md          # 大型支线（独立完整流程）
├── misc/*.md                  # （预留）独立小支线
└── _draft/                    # 素材底稿（不入编译）
```

- 每个文件 = 一个「流程」（主线章 / 大型支线），`type` 由所在目录推断。
- 主线章内嵌小型支线任务卡（见 §6），不单独建文件。

## 2. Front Matter（文件头）

```markdown
---
id: main-01            # 流程 id（全局唯一；缺省用文件名）
title: 初出茅庐         # 显示标题
group: 入门之前          # 章组（主线章必填：入门之前/入门弟子/晋升资深/晋升精英/晋升传功/晋升执法/烟尘回响）
order: 1               # 排序
source: 模板/综合        # 内容来源标注
---
```

## 3. 步骤语法

```markdown
## [main-1] 梧桐村·江吟风
正文段落……（可含 [[链接]]，见 §5）

> window: 碧海仙踪开启于 [[main-13]] 后
> link: 关联 [[quest-碧海仙踪]]
> 存档：学武三选一前
> 必选：不风山前触发
> 掉落：心火丹
> 队友入队：卫霍（全程升级位）
> 来源：模板 s1
> 补充：梧村·Luc 支线细节（Excel 综合）
```

- `## [别名] 标题`：**别名（方括号内）就是步骤 id**，链接就写它——建议主线用 `main-N`（N=全局主线序号），大支线用 `xx-N` 或语义名。
- `## 标题`（无别名）：自动编号 `流程id:序号`。

## 4. 元行（`>` 开头一行）

| 元行 | 前端渲染 |
|---|---|
| `> window: …` | ⚠ 窗口条（原文保留 `[[...]]`，渲染为胶囊） |
| `> link: …` | 关联说明（原文保留 `[[...]]`） |
| `> 存档：…` | 🅢 存档徽章 |
| `> 必选：…` | 🔴 必选徽章 |
| `> 掉落：…` | 🗡 掉落徽章 |
| `> 队友入队：…` | 🧑🤝🧑 入队提示 |
| `> 来源：…` | 来源标注 |
| `> 补充：…` | 📋 补充信息块（跨文档差异细节） |

元行不进正文；其他 `> 任意文本` 会被当作正文渲染。

## 5. 链接语法 `[[ref]]`

正文任意位置写 `[[引用]]`，编译时解析、前端渲染为**可点击胶囊 ↗**，并**自动生成回链**（被引步骤底部显示「← 从这些步骤跳入」）。

| ref 写法 | 目标 | 示例 |
|---|---|---|
| 步骤 id（别名） | 指定步骤 | `[[main-43]]`、`[[bihai-3]]` |
| `流程id:序号` | 流程内第 N 步 | `[[main-01:5]]` |
| `流程id-N` | 同上（简写） | `[[main-01-5]]` |
| `流程id` / 流程标题 | 整章 | `[[quest-碧海仙踪]]`、`[[碧海仙踪]]` |
| `misc:任务名` | 小型支线任务卡 | `[[misc:小铜木剑（隐藏）]]` |

## 6. 小型支线任务卡（独立数据文件）

小型支线**不建 md**，任务卡统一维护在 `content/misc-tasks.json`（手工可编辑；重跑 `tools/gen-misc-tasks.mjs` 只补充隐藏条目，不覆盖手改）：

```json
{ "name": "山猪为患", "open_after": 4, "close_before": 12,
  "trigger": "野猪林：和猎人交谈接取",
  "prereq": "", "gains": ["山猪肉"], "fav": [{"who": "卫霍", "val": "+10"}],
  "steps": ["模板原文步骤…"], "source": "template" }
```

- `open_after/close_before` = 主线步序号窗口（打开/关闭坐标）；
- 前端按 `open_after` 自动归入对应主线章展示：📍触发 / 🔒前置 / 🎁收益 / 💗好感（好感可点击跳人物页）；
- 队友档案 `content/companions.json` 同理手工可编辑，个人支线 `ref` 写 `misc:<任务名>` / `main-N` / 步骤 id。

## 7. 渲染行为约定

- 链接胶囊文案：步骤 → 「章名·步骤标题」（去掉 `主线 N｜` 前缀）；流程 → 流程标题；misc → 「支线 · 任务名」。
- 未解析链接（编译告警 `⚠️ 未解析链接`）渲染为灰色胶囊并保留原文——**上线前必须清零**。
- 打勾进度存 localStorage（`ws_guide_progress_v2`），按步骤 id 记录。

## 8. 新增内容操作示例

**新增大型支线**：`content/flows/quest/新支线名.md`（front matter + 步骤 + 元行）→ `npm run sync:data` → 前端自动出现在首页大支线区；再在相关主线步加 `> link: [[quest-新支线名]]` 建立双向跳转。

**新增小型支线**：直接在 `content/misc-tasks.json` 加一条任务卡；若含隐藏任务（模板无记载），`source` 写 `curated` 并给出触发/收益/好感信息。
