## 2. 修订后的章节轴（三层结构）

**层级**：章组（身份等级，仅做分组/筛选）→ **章**（模板区块，索引基本单位）→ **主线步骤**（窗口标注最小单位）

**重大修正**（基于模板全文再定位）：
- "品剑大会"章的开场主线是**挑战道通晋升精英弟子**——所以等级链为：入门弟子 → 资深弟子 → **精英弟子** → 传功弟子 → 执法弟子 → 终局（无新晋升）；
- **不风山**主线步位于"关外风云"章（"前往黎城(瑶姬离队)→…→前往不风山触发剧情进入战斗"）——这是武家旧事 DLC 的官方关闭坐标；

## 4. 卡片设计（修订）

### 4.1 主线章节卡（13 张）
1. 头部：章序号 · 章组（等级）· 章名 · 主线坐标摘要
2. 主线流程攻略：主线步骤序列（步骤级 🔓开启 / 🔒最后窗口 内联标注；附存档点/成就/分支）
3. 本卡开启支线区（→ 链接任务卡）
4. 本卡最后窗口区 ⚠️（→ 链接任务卡，注明"关闭于本卡哪一步之后"）
5. **备注区（每卡必带）**：该章全部模板备注按顺序列出，默认展开可折叠
6. 底部导航 ← 上一章 → 下一章

### 4.2 大型支线卡（8 张）
- 头部：名称 · 徽章（大型支线 / **DLC** / 旧主线）· 所属章链
- 窗口块：🔓开启条件（含前置任务链）· 🔒最后窗口（含来源引用链接；**未证实项灰色标注**）· 互斥/分支提示（如异种金蝎三线）
- 阶段化流程：每阶段标注对应主线章/步骤坐标
- 备注区（必带）
- 特殊：旧主线卡内含"速通 30 步 + 全流程 + 存档点轮转"多周目路线图

### 4.3 小型支线卡
- 名称 · 所属章 · 🔓/🔒窗口 · 流程步骤 · 奖励 · 备注区

### 4.4 零弹窗规范（新）
- **全局无 modal 弹窗、无响铃/振动/推送、无浏览器通知**；页面内所有提醒（最后窗口警告、完成反馈、分支提示）均以**内嵌色条/角标/卡片**呈现；系统级 service worker 仅用于离线缓存，不发任何通知。

### 4.5 准备·传承卡（游戏开始前，专题区，新）
- **二周目继承建议**：按模板六类拆分六张子卡——传承 / 棍法 / 心法 / 拳法 / 暗器 / 剑法（每项含 继承点消耗、获取条件、适用路线）
- **开局设置与难度建议**（来自 v1.24 完美攻略：大招显示/字体/固定镜头/Q键位、萌新困难一周目、极难二周目）
- **存档点总览卡**：新主线 7 存档点 + 旧主线 5 存档点 + 双线图鉴解锁路线表
- **速通专题**：新主线速通 27 步卡 + 旧主线速通 30 步卡（多周目全图鉴向）

### 4.6 首页
章节时间轴卡片流 · 大型支线总览 · 最后窗口全局角标（"当前有 N 个支线处于最后窗口"，内嵌式）· 搜索（全局）· 本机进度打勾（localStorage 离线可用）

## 6. 核对细节清单（M5 阶段执行，先列出供你知悉）

- **A. 任务名规范化**：同名多段合并（如无妄蛇灾×3、山猪为患×3）；"百晓生-XX""蓬莱遗珍-XX""歪僧慧达(一~四)"系列归属；同名异任务拆分（旧/新主线的 比武招亲、云相太极）。
- **B. 主线步骤粒度**：模板一行长串（一行为多箭头流程）是否拆为可挂窗口的子步；拆法统一（按场景/战斗/对话断点）。
- **C. 窗口坐标对位**：每个 🔓/🔒 映射到 具体章+步骤；外部节点（不风山/南疆/天水祝寿/送丹药/百善未及一恶）在模板中的坐标逐一落地；模板原句模糊处（如"南疆会关闭"备注）标记"语义待核"。
- **D. 双重展示一致性**：同一窗口事实在"步骤内联"与"章末最后窗口汇总"两处显示一致（数据单源，渲染两处）。
- **E. 分支/互斥标注**：异种金蝎三线、飞蝎使赠予/交换、凤凰洞欧阳雪/顾思归、天机宫重建抉择、程钰留否/掌门、莫问好感度阈值、绝响难求做与不做。
- **F. 备注归属**：每条备注挂到最近的步骤或任务；"每卡必带备注"不遗漏、不串卡。
- **G. 存档点**：坐标、存档目的（结局/图鉴分支）、双主线存档点映射。
- **H. 数值抽查**：奖励道具/钱数额、好感度数值、成就名，抽样对模板原文。
- **I. 大型支线阶段划分**：跨章阶段归属（如武家旧事：武当→和璞山庄→试剑台→收尾）；"暂时关闭/重新开启"的复开条件。
- **J. 旧主线卡互链**：主线章节卡在"霹雳门附近"提示"此处可入旧主线"，旧主线卡反向引用。
- **K. 来源引用**：外部窗口证据（官方说明/B站/9game/切游/700g/游侠）在卡上标注出处链接与核查日期；游戏版本锚点（**v1.24.32**）显示于关于页。
- **L. 待核清单维护**：无证据关闭点（伤魂鸟/霹雳门/甘泉苦水/绮罗筵 的硬关闭）保持"未证实"灰标，证据出现后转绿并记来源。
